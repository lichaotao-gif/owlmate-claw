# OwlMate · 投资驾驶舱

首页交互演示：资产快照、持仓上下文、组合情景推演、仓位与现金联动、规则式对话、新资金试算、事件演示、画像与本机方案保存。

## 范围

`/my-strategies` 提供个人策略与收藏策略卡片，复用原策略库、创建器与实验室交接。文字、语音和文档输入可整理成草案，生成阶段可取消；保存后提示创建测试实验。个人策略可编辑，编辑保留 ID 与创建时间，收藏策略来源受保护。策略目前按浏览器源保存在本机，生成使用已有关键词规则，不是大模型服务；测试入口不等于任意规则已完成历史回测。运行 `npm run verify:strategies` 验证策略编辑、容量、来源与阶段取消逻辑。

嵌入 OwlMate 工作台时自动隐藏内部侧栏、账号登录与积分入口；实验室头部保留右上角「策略广场」与「使用指南」，广场保留返回实验室。独立窗口打开仍使用原导航。当前只整合界面，账号和积分尚未与外层系统打通。

嵌入时日间/夜间外观跟随工作台右上角的主题设置，通过仅传递主题枚举的窗口消息同步；独立打开时保留自身的主题偏好。

界面统一使用研究产品文案，实验曲线与虚拟资产的使用范围集中在页脚可展开的「数据说明」中。文案调整不代表接入真实行情、账户或交易。

所有行情、历史曲线、事件和资产均为虚构示例。未来路径为情景示意，不是蒙特卡洛概率。对话为显式标注的预设意图响应，未连接语言模型、券商或真实行情。保存计划不执行交易。

## 策略使用引导

策略广场、个人策略库和实验室为空时显示四步开始卡片，创建按钮接入现有创建流程；右上角「使用指南」随时打开带蒙层的编号图解。图解支持步骤切换、前后翻页和开始创建，并跟随日间/夜间主题。不自动弹出或修改本机已有策略。`npm run verify:guide` 检查空市场推荐项处理与步骤边界；真实浏览器操作仍需人工验收。

## 复盘对象选择

`/review-holdings` 为工作台提供实验持股的最小数据读取：仅传递证券名称、代码和实验名称，不提供金额或交易记录。开发环境允许本机 3000 端口工作台，线上跨域嵌入时需构建前设置 `NEXT_PUBLIC_OWLMATE_CONSOLE_ORIGIN` 为完整工作台源地址（例如 `https://console.example.com`）；非受信源不会收到持股数据。实验数据目前按浏览器源保存，尚未按账号隔离。运行 `npm run verify:review-holdings` 检查来源验证与持仓筛选。

## 多电脑同步与运行

每次开始工作：

```bash
cd ~/Documents/www/owlmate-claw
npm run work:start
```

每次结束工作：

```bash
npm run sync:up -- "本次修改说明"
```

如果另一台电脑已经克隆过旧版本，先执行一次：

```bash
git pull --ff-only origin main
```

之后即可使用上述两个一键命令。最重要的顺序是：上一台电脑先执行 `sync:up`，下一台电脑再执行 `work:start`。

`work:start` 会先确认处于 `main` 分支、本机没有未提交修改，以快进方式拉取远端；仅在缺少依赖时按照 `pnpm-lock.yaml` 安装。随后它会在 `http://localhost:3018/` 启动开发服务器、检查首页响应、自动打开浏览器，并保持服务运行。也可单独运行 `npm run sync:down`，只同步代码和依赖，不启动服务。

`sync:up` 会先检查 TypeScript，再提交全部本机修改、rebase 合并远端更新，最后推送到 GitHub；若发生冲突会停止，不会强行覆盖。同步成功后，它还会停止由本次 `work:start` 启动的开发服务。

项目保留 pnpm 锁文件。也可单独使用 `pnpm dev` 启动开发环境、使用 `pnpm build` 进行生产构建。若本地 pnpm 自动安装策略阻碍启动，可直接使用 `node node_modules/vinext/dist/cli.js dev`。

## 模拟

20 日风险资产收益假设：上涨 8%、震荡 1.5%、下跌 -10%；其他周期按复利缩放。现金收益为零；交易费用按风险资产调整额的 0.1% 计算。先扣除费用，再按目标比例配置风险资产和现金。风险资产按原始 30:20:18:12 比例分配。`lib/simulation.ts` 是数字计算的单一来源。

## 导出单文件复刻参考

运行 `npm run export:html`，生成 `outputs/OwlMate-单文件参考.html`。只需发送这一个文件，直接用浏览器打开即可查看全部页面、切换主题和操作前端演示，无需安装依赖或启动服务器。样式、图片和运行脚本全部内嵌；演示数据保存在接收者浏览器中，不导出本机账户数据。

给开发同事的 Codex：请读取 HTML 中 `owlmate-reference-sources` 内嵌的原始源码，并在真实浏览器中对照页面复刻。重点保持 `app/globals.css` 的字体、颜色、尺寸、间距及响应式布局，逐页核对深浅主题、弹窗和交互，不要重新设计。原项目页面路径在单文件中使用 `owlmate-page` 查询参数切换。
